# Community Demo

Demo visual de plataforma de comunidades tipo Skool. Proyecto estático con HTML5 + CSS3 puro.

## 🚀 Quick Start

```bash
# Instalar dependencias
npm install

# Ejecutar servidor de desarrollo
npm run dev
```

Luego abrí http://localhost:3000 en tu navegador.

## 📁 Estructura del Proyecto

```
community-demo/
├── index.html              # Landing/Home de la comunidad
├── community-feed.html     # Feed principal con posts
├── courses.html            # Listado de cursos
├── course-detail.html      # Detalle de un curso
├── members.html            # Directorio de miembros
├── css/
│   └── styles.css          # Estilos globales
├── js/
│   └── main.js             # JavaScript para interactividad
└── assets/
    └── (imágenes placeholder)
```

## 🎨 Características

- ✅ Diseño responsive
- ✅ Navegación tipo Skool
- ✅ Sistema de gamificación visual
- ✅ Cards de posts, cursos y miembros
- ✅ Leaderboard interactivo
- ✅ Sin dependencias de frameworks
